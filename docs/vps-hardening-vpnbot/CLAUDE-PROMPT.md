# Как поручить Claude проверить/починить сервер по этой инструкции

Скопируйте текст ниже в чат с Claude (с доступом к серверу по SSH или через ваш компьютер), подставив свои данные.

---

Проверь мой VPS по инструкции из моего репозитория `alexirgas/other`, папка `docs/vps-hardening-vpnbot`
(README.md и scripts/). Данные: IP `___`, порт SSH `___`, пользователь root, вход по ключу `___`.
На сервере работает vpnbot_extra в Docker (папка `/root/vpnbot_extra`).

Порядок:
1. Прочитай README.md и скрипты. Скопируй папку scripts на сервер и сделай `sed -i 's/\r$//' *.sh`.
2. Запусти `sh audit.sh` (только чтение) и покажи таблицей, что FAIL/WARN.
3. Для каждого пункта предложи нужный скрипт, сначала запускай БЕЗ `--apply` и покажи, что он собирается сделать.
4. С `--apply` запускай только после моего «да» на каждый шаг. Шаги 06, 07, 10 перезапускают контейнеры: предупреждай заранее;
   шаг 01 - только после того, как вход по ключу проверен в отдельном сеансе.
5. Всегда сначала шаг 05 (бэкап), потом 06-10. Ничего не удаляй (исключение: шаг 17 чистит кэш и неиспользуемые образы Docker, только после моего «да» и с показом списка в пробном режиме; образы backup-* не трогай). Права на файлы не меняй. Логи из списка KEEP не чисти.
6. После каждого шага проверяй `docker ps` и работу бота. В конце снова `audit.sh` и краткий итог «до/после».
7. Если скрипт остановился с [FAIL] - не обходи проверку, покажи вывод и объясни причину.
8. Секреты (ключи, токен бота, содержимое config/) не печатай в чат и не коммить в репозиторий.

Режим «только проверка»: выполни только пункты 1-2 и дай отчёт, ничего не меняя.
